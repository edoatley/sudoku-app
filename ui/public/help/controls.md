# How to Play

## Selecting a Cell

Click or tap any cell to select it. The selected cell is highlighted blue. All cells in the same row, column, and 3×3 block are shaded purple, and any other cells containing the same digit are shaded light blue.

Click or tap the same cell again to deselect it.

## Entering a Digit

There are two ways to place a digit:

- **Cell first:** Select a cell, then click a number button (1–9) or press a number key.
- **Number first:** Click a number button, then click the cell you want to fill.

## Candidate (Pencil Mark) Mode

Switch to **Candidate** mode using the toggle in the toolbar or press **Space**. In candidate mode, digits are entered as small pencil marks in the cell rather than as a placed value. Press the same digit again to remove that candidate.

Switch back to **Normal** mode to place definitive digits.

## Clearing a Cell

Select a cell and then:

- Click the **Clear** button in the toolbar, or
- Press **Delete**, **Backspace**, or **0**

Clearing removes both the placed digit and all candidates.

## Keyboard Shortcuts

| Key | Action |
|---|---|
| `1` – `9` | Enter digit (normal mode) or toggle candidate (candidate mode) |
| `0` / `Delete` / `Backspace` | Clear selected cell |
| `Arrow keys` | Move selection up / down / left / right |
| `Space` | Toggle Normal ↔ Candidate mode |
| `Escape` | Deselect current cell |

> Arrow keys are clamped at the grid edges — the selection stops at row 0, row 8, column 0, or column 8.

## Toolbar Buttons

| Button | Action |
|---|---|
| **Undo** | Undo the last cell edit |
| **Clear** | Clear the selected cell (Del or 0) |
| **Check** | Validate the current board and highlight any errors |
| **Hint** | Request a solving hint |
| **Fill** | Fetch and fill in all valid candidates for every empty cell |
| **?** | Open this help page |

## Hints

Click **Hint** to request a hint. Hints are revealed in three stages:

1. **Nudge** — a general clue about which technique applies and which cells are relevant.
2. **Focus** — a more specific pointer to the key cell or pattern.
3. **Reveal** — the full solution: candidates are eliminated and/or a cell is filled in.

Use **Try Different Hint** at any stage to see an alternative technique.

## Pausing

Click the **Pause** button in the header to pause the timer and hide the board. Click **Resume** to continue.

The game auto-pauses after 3 minutes of inactivity.

## Saving

Your game is saved automatically every 60 seconds and when you leave the page. It is also saved locally in your browser so it reloads instantly when you return.
